# Lead Gen Kit

Turns raw lead capture data into prioritised prospects by combining parsing, embeddings, and intent scoring.

## Included Blocks

- `parser-csv-json@0.1.0`
- `embedder-bge-small@0.1.0`
- `classifier-intent@0.1.0`

## Flow

1. Parse inbound CSV/JSON dumps of lead forms.
2. Generate embeddings for deduplication and similarity.
3. Score intent to prioritise outreach queues.

Review `manifest.json` to adjust block versions or add configuration defaults.
